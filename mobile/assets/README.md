# Assets

Put your logos here. The app reads these three images (from `app.json`):

- `images/icon.png` — app icon, 1024x1024 PNG
- `images/adaptive-icon.png` — Android adaptive icon foreground, 1024x1024 PNG (logo with transparent padding)
- `images/splash-icon.png` — splash logo, 1024x1024 PNG (shown on transparent `#141020` background)

Optional:
- `icons/` — fallback UI icons (currently the app uses `@expo/vector-icons`)
- `images/` — share your thumbnails/artwork here

The current PNGs are 1x1 placeholders so builds won't fail. Replace them before
building the APK so your icon appears in the launcher.
